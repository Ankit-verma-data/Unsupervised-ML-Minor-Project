# Smartcart System - Customer Segmentation (Unsupervised Machine Learning)

An end-to-end unsupervised machine learning project focused on customer segmentation using shopping behavior data.

## 🚀 Project Overview
This project analyzes customer demographic and purchasing data to segment buyers into distinct groups using clustering algorithms. This helps businesses understand customer behavior and optimize targeted marketing strategies.

## 🛠️ Tech Stack & Libraries
* **Programming Language:** Python
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-learn (K-Means, Agglomerative Clustering, PCA, StandardScaler)
* **Data Visualization:** Matplotlib, Seaborn
* **Environment:** Jupyter Notebook

## 📊 Project Workflow
1. **Data Preprocessing & EDA:** Handled missing values, removed outliers, engineered features (Age, Total Spending, Tenure), and analyzed correlations using heatmaps.
2. **Dimensionality Reduction:** Applied StandardScaler and Principal Component Analysis (PCA) for 3D feature transformation and visualization.
3. **Cluster Optimization:** Utilized the Elbow Method and Silhouette Score to determine the optimal number of clusters ($K=4$).
4. **Clustering & Profiling:** Implemented K-Means and Agglomerative Clustering algorithms to segment customers and profile their purchasing patterns.

## 📂 Repository Structure
* `smartcart_customers.csv`: Dataset used for the analysis.
* `Smartcart.ipynb`: Jupyter Notebook containing the complete code, visualizations, and model implementation.
